지금 비밀번호로 보드를 한 번 열어 보고, 새 비밀번호로 다시 잠근 index.html을 만들어 드려요.

최신 index.html 파일이 따로 있으면 첨부 (선택)

첨부하면 내장된 자료 대신 그 파일에 들어 있는 오늘 내용으로 만들어요. 화면(잠금 방식)은 이 도구에 들어 있는 비밀번호 입력 화면으로 새로 만들어져요.

내장된 자료:

✓

새 index.html을 만들었어요

  1. GitHub 업로드 페이지 열기 tingga-board 계정으로 로그인된 브라우저여야 해요.
  2. 방금 받은 index.html을 그 페이지에 끌어다 놓기 같은 이름이라 지금 파일을 그대로 덮어써요.
  3. 아래로 내려 Commit changes 누르기
  4. 1분쯤 뒤 새로고침 → 새 비밀번호로 열려요 홈 화면에 추가해 둔 앱은 완전히 닫았다가 다시 열어 주세요.

업로드하기 전까지는 지금 비밀번호가 그대로예요. 마음에 안 들면 다시 만들어 덮어쓰면 됩니다.

이 파일은 내 컴퓨터 안에서만 돌아가요. 입력한 비밀번호와 보드 내용은 어디로도 보내지 않고, 인터넷 없이도 됩니다. 만들어지는 index.html에는 새 비밀번호가 글자로 남지 않아요 — 200,000번 늘려 만든 열쇠로 내용을 잠그고, 열쇠는 파일에 넣지 않아요.
